# Sistema de Mensajería

Proyecto Layout-Ecommerce-Grid desarollado por Israel Aguilera como práctica de maquetación con HTML y CSS, enfocado en el uso de Grid para construir una Layout-Ecommerce con Grid.

## Acceso github pages
    https://buffonico.github.io/Layout-Ecommerce-Grid/
## Acceso a github proyecto
    https://github.com/buffonico/Layout-Ecommerce-Grid
    
    

## La página muestra una aplicacion de una tienda E-commerce distribuida con Grid que son:

    Un panel superior, que nos muestra el titulo
    Un panel lateral con categorias de compras del usuario.
    Un área principal con imagenes de productos con un boton de comprar.

## El diseño utiliza imágenes locales, distribución Grid, botones, estados hover y focus, además de estilos personalizados para simular iconos de menú (categotias) y compras.

## Tecnologías Utilizadas

    HTML5
    CSS3
    Grid

## Características

    Layout principal construido con Grid.
    Panel de categorias fijo al costado izquierdo.
    Sección principal centrada vertical y horizontalmente.
    Imágenes de productos.
    Botón de compras con estado hover y focus.
    Iconos creados con CSS.
